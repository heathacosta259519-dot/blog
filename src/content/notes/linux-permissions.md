## 一行 ls -l 拆成四段

```text
-rwxr-xr--  1 akagi users  4096 Oct 30 21:12 deploy.sh
```

从左往右，每一段的意思：

| 段 | 例子 | 含义 |
| :--- | :--- | :--- |
| 1 | `-` | 类型：`-` 文件、`d` 目录、`l` 链接、`s` 套接字、`p` 管道、`c`/`b` 设备 |
| 2–4 | `rwx` | 属主权限 |
| 5–7 | `r-x` | 属组权限 |
| 8–10 | `r--` | 其他人权限 |
| 11 | `1` | 硬链接数 |
| 12–13 | `akagi` `users` | 属主、属组 |
| 14 | `4096` | 字节数 |
| 15 | `Oct 30 21:12` | 最后修改时间 |
| 16 | `deploy.sh` | 文件名 |


三个三元组，顺序永远是**属主 → 属组 → 其他人**。目录上的 `x` 表示"能进去"（cd），`r` 表示"能列出内容"（ls），只有 `r` 没有 `x` 的目录是个陷阱：看得见文件名，打不开文件。

## 八进制怎么来的

| 位 | 值 | 权限 | 对文件 | 对目录 |
| :--- | :---: | :--- | :--- | :--- |
| 4 | `r` | 读 | 查看内容 | 列出条目 |
| 2 | `w` | 写 | 修改内容 | 增删条目 |
| 1 | `x` | 执行 | 作为程序运行 | 进入 / 访问其中文件 |

按位相加就行，`rwx = 4+2+1 = 7`，`r-x = 4+1 = 5`，`r-- = 4`。

```bash
chmod 754 deploy.sh     # 属主 rwx，属组 r-x，其他人 r--
chmod u+x deploy.sh     # 只给属主加执行位
chmod -R g-w shared/    # 递归去掉属组的写权限
```

`umask` 决定新建文件的默认权限，是"要扣掉的位"，不是"给的位"：

```bash
umask          # 常见 022 → 文件 644，目录 755
umask 077      # → 文件 600，目录 700（私有）
```

注意目录的基准是 `777`、文件是 `666`（文件默认不给执行位）。

## 特殊位：SUID / SGID / Sticky

这三个位占用八进制的最前面一位，共四位：

| 位 | 八进制 | 作用 |
| :--- | :---: | :--- |
| SUID | `4000` | 执行时以**文件属主**身份运行 |
| SGID | `2000` | 文件：以属组身份运行；目录：新建文件继承该目录的属组 |
| Sticky | `1000` | 目录内只有属主能删除自己的文件（`/tmp` 就靠它） |

```bash
ls -l /usr/bin/passwd
# -rwsr-xr-x  ← 属主位的 s，就是 SUID
```

`passwd` 需要写 `/etc/shadow`，普通用户没权限，所以它带着 SUID 以 root 身份运行。

**SUID 是提权面**。一个自己写的、能被普通用户替换内容或注入参数的 SUID 程序，基本等于送 root。所以：

- 不要给自己写的脚本加 SUID —— Linux 内核对脚本的 SUID **直接忽略**，加了也没用，反而是个思维陷阱。
- 排查机器时先跑 `find / -perm -4000 -type f 2>/dev/null`，看有没有不该在的。

## 别把 777 当万金油

`777` 的意思是"任何人都能改"。Web 目录给 777，等于给上传目录一个变成 webshell 的通道；配置文件给 777，等于把密钥交给机器上每一个进程。

按用途给：

```bash
chmod 755 /var/www/html          # 目录：别人能读能进，不能写
chmod 644 /var/www/html/*.html   # 文件：别人只读
chmod 600 ~/.ssh/id_ed25519      # 私钥：只有自己
chmod 700 ~/.ssh                 # 目录：只有自己
```

## 排查清单

- `namei -l /path/to/file` —— 逐级显示路径上每一层的权限，`Permission denied` 时先看这个，问题经常不在最后一层。
- `getfacl` / `setfacl` —— 权限位不够用时才上 ACL，别一上来就用。
- `lsattr` —— 改不动文件也可能是 `+i`（immutable），跟权限无关。
